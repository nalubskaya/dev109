Project Description: Pottery Studio Website This project aims to develop a comprehensive and engaging website for a pottery studio and shop. The website will serve as a central hub for all aspects of the business, showcasing our handcrafted pottery, promoting our classes advertising our pottery painting party services, facilitating custom orders, and featuring special holiday items. The site will be built using HTML for structure, CSS for styling, and JavaScript for interactive elements.
